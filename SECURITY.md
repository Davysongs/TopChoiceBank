# Security

TopChoiceBank v2 is an engineering demonstration and currently does not process real financial data.

## Security boundaries for this stage

- No authentication system is implemented yet.
- No user data is persisted by this foundation.
- The database layer is scaffolded but not yet wired to sensitive flows.

## Reporting security issues

If you find a potential security issue, please report it through GitHub security advisories for the repository.
Include reproduction steps and potential impact.
